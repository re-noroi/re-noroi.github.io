About Me

I am a systems developer with a strong focus on low-level programming, OS internals, and performance optimization. I specialize in modifying, maintaining, and compiling Linux-based custom kernels for Android devices.

My work involves backporting upstream scheduler updates, tweaking memory compression, and automating complex build pipelines to deliver highly optimized system performance.

Featured Work

FakeDreamer Custom Kernel (SM8250)

A highly optimized, custom Linux kernel maintained for Qualcomm Snapdragon 865 (SM8250) devices, specifically targeting the POCO F3 (alioth), Apollo, and Munch.

  • Scheduler Optimization: Integrated EEVDF scheduler backports and custom DVFS headroom sysctl tunables for improved CPU power management.
  • System Integration: Built-in KernelSU support for seamless root-level access and management.
  • Memory & Performance: Configured advanced zRAM memory compression and BPF implementations for enhanced multitasking.
  • CI/CD & Deployment: Automated the entire compilation and variant-branching process using GitHub Actions and AnyKernel3 flashing scripts.
